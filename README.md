# AI Life - 微信风格 AI 聊天模拟器

一个模拟微信手机界面的 AI 聊天应用，支持多角色对话、生活模拟、朋友圈等功能。

## 功能特性

- 📱 微信风格 UI 界面
- 🤖 多角色 AI 对话
- 🧠 LifeAgent 生活模拟系统
- 📝 记忆提取与世界书
- 📅 日程系统
- 🖼️ 朋友圈功能
- 💰 钱包与转账模拟

## 技术栈

- 纯前端实现（HTML + CSS + JavaScript）
- 支持 PWA
- localStorage 本地存储

## 使用方法

直接用浏览器打开 `ai-life.html` 或部署到任意静态服务器。

## 配置

在设置页面配置你的 AI API：
- API 端点
- API Key
- 模型名称
